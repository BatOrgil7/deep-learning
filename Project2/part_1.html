Task 1. Source points come from a standard 2D Gaussian N(0, I). The target is a ring of radius 2: angle uniform in [0, 2π), radius = 2 + 0.1 × Gaussian noise. Both use the same coordinate scale (most noise points fall within ±3). Each noise point is randomly paired with a ring point, and t is drawn uniformly from [0, 1]. The velocity along each training path is constant because the path is a straight line travelled at constant speed: x_t = x0 + t(x1 − x0), so the change per unit time is always x1 − x0, no matter what t is.

Task 2. The network receives only the current position x_t and time t, and predicts the velocity x1 − x0. It never sees the start or end point. Because pairs are random, many pairs pass through the same position and time with different velocities, so the best the network can do is predict their average. That's why the loss levels off (about 3.84) instead of going to zero.

Task 3. Generation starts from fresh Gaussian noise with no endpoints given, and follows the learned velocity for 100 Euler steps. The training paths are straight and cross each other. The learned paths are curved and don't cross, because the model gives only one velocity per position and time: it follows the average of many crossing training lines, and that average changes direction as the point moves. Straight training paths do not guarantee straight sampling paths.
