Project 0, Part 2: Basic Attention Mechanism¶

An encoder–decoder model with Bahdanau (additive) attention, trained on the English–French machine translation dataset from D2L. The encoder is a GRU that reads the English sentence and emits one hidden state per input token. The decoder is a GRU that generates French one token at a time, and at each step computes a weighted average over all encoder states rather than relying solely on the encoder's final state.

The attention module is implemented directly rather than taken from the d2l library.

Task 1: Implement and train the attention model¶

Additive attention¶

At each decoder step the module receives:

  • query — the decoder's current hidden state, representing what it is looking for
  • keys and values — the encoder's hidden states, one per input token (in Bahdanau attention keys and values are the same tensor)
  • valid_lens — true input lengths, so padding positions can be masked out

It computes a relevance score for each encoder position, normalizes the scores with softmax, and returns the weighted average of the encoder states.

The scoring function is additive: query and keys are each projected into a shared space by learned matrices W_q and W_k, summed via broadcasting, passed through tanh, and collapsed to a scalar by w_v. Unlike dot-product scoring this permits query and key to have different dimensions, and the learned projections let the model decide what "relevant" means rather than relying on raw vector alignment.

The attention weights are stored on the module at each call so they can be retrieved for visualization in Task 2.

Decoder¶

At each generation step the decoder:

  1. Takes its current hidden state as the query
  2. Runs attention over all encoder outputs to produce a context vector
  3. Concatenates the context vector with the embedded input token
  4. Feeds the result through the GRU to produce a new hidden state
  5. Maps that state to logits over the French vocabulary

Step 2 is the entire difference from a plain seq2seq decoder. Without it, the decoder would receive only the encoder's final hidden state and all information about the source sentence would have to pass through that single fixed-size vector.

Both settings translate three of the four test sentences exactly and both fail on the same sentence, he's calm .. Setting A produces sois calme ., which retains the adjective but renders the sentence as an imperative rather than a third-person statement. Setting B produces je suis ., which loses the adjective entirely and substitutes a first-person subject.

The shared failure on the same input is more informative than the difference in severity. he's calm . is the only test sentence requiring a third-person subject pronoun, and neither model handles it. This suggests the training corpus is dominated by first- and second-person constructions, so the error is a property of the data rather than of model capacity.

Setting A's loss curve shows a large gap between final training loss (0.106) and validation loss (1.797), indicating substantial overfitting by epoch 30. The dataset's short, repetitive sentence pairs are easy for a 2-layer, 256-unit model to memorize. Setting B has roughly a quarter of the parameters, and the comparison of its train/val gap against Setting A's indicates whether the reduced capacity meaningfully limits memorization at this dataset size.

Since BLEU is identical on three of four sentences, the additional capacity in Setting A buys very little on this task. Sentences of two to four content words do not require a 256-unit, 2-layer encoder–decoder, which is consistent with the flat attention maps discussed in Task 2.

Task 2: Visualize and interpret attention¶

The attention weights form a matrix with one row per French output step and one column per English input position. Each row sums to 1. A bright cell means the decoder drew heavily on that input token when producing that output token.

What the heatmaps show¶

Across all test sentences, attention concentrates on the first one or two input columns at every output step. There is no diagonal alignment pattern.

Verifying the axis is correct: printing the tokenized source for i'm home . gives ["i'm", 'home', '.', '<eos>'], so the four plotted columns are three real tokens plus the end-of-sequence marker. No padding is included in the visualization, and the flat pattern is not an artifact of the slice.

The likely cause is sentence length. The training pairs in this dataset are very short — typically two to four content words. A GRU hidden state of 256 units carries a sentence that short without difficulty, so the decoder has no pressure to selectively re-read the input. The attention weights converge toward a near-uniform distribution skewed to early positions, and the translations remain accurate regardless.

This is consistent with the original motivation for attention: it was introduced to address degradation on long sequences, where a fixed-size encoder state becomes a genuine bottleneck. At this sentence length that bottleneck does not bind, so the mechanism provides little measurable benefit.

A helpful case¶

i lost . → j'ai perdu . (BLEU 1.000). Attention concentrates on columns 0 and 1, the positions of "i" and "lost". Although the pattern is not a clean diagonal, the weight is placed on the content words rather than on punctuation or the end-of-sequence token, and the translation is exact.

A less successful case¶

he's calm . → il est mouillé . (BLEU 0.658). The attention distribution is flatter than in the other examples, with no clear peak on the token corresponding to "calm", and this is the only sentence the model translated incorrectly. The absence of a sharp focus on the relevant adjective coincides with the model substituting an unrelated adjective in that slot.

Out-of-vocabulary failure¶

Testing on a longer constructed sentence, he is not a good student ., the model output <unk> . — it produced an unknown token and failed to translate at all. The attention map for this input is uninformative because the decoder never generated meaningful content.

This reflects a dataset limitation rather than a flaw in the attention implementation. The training corpus consists of short, simple sentence pairs, so vocabulary coverage is narrow and the model has no training signal for inputs of this length or composition.

Summary¶

The attention mechanism trains and produces accurate translations, achieving BLEU 1.000 on three of four held-out sentences. However, the attention weights are not interpretable as word alignments on this dataset. Demonstrating the alignment behaviour attention is known for would require a corpus with longer sentences and broader vocabulary coverage, where the fixed-size encoder state becomes a real constraint.
